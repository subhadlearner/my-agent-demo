# My Agent Demo

## Project Overview

`my-agent-demo` is a sample project showcasing how to build an AI-powered documentation assistant using OpenAI's GPT models. The project demonstrates:
- Reading and searching repository files.
- Generating and updating documentation automatically.
- Managing branches and pull requests programmatically.

The goal is to provide a clear example of how AI can assist developers in maintaining up‑to‑date project documentation.

## Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/your-username/my-agent-demo.git
   cd my-agent-demo
   ```

2. **Create a virtual environment** (optional but recommended)
   ```bash
   python -m venv venv
   source venv/bin/activate   # On Windows use `venv\\Scripts\\activate`
   ```

3. **Install the required dependencies**
   ```bash
   pip install -r requirements.txt
   ```

   > **Note**: If the `requirements.txt` file does not exist yet, you can generate it with:
   > ```bash
   > pip freeze > requirements.txt
   > ```

## Usage Examples

Below are a few common tasks you can perform with this project.

### 1. Generate Documentation for a New Module
```bash
python main.py generate-docs path/to/module.py
```
This command reads the specified Python file, extracts docstrings, and creates a Markdown documentation file in the `docs/` directory.

### 2. Update the README Automatically
```bash
python main.py update-readme
```
The script analyses the repository structure and inserts a project overview, installation steps, and usage examples into `README.md`.

### 3. Open a Pull Request with Documentation Changes
```bash
python main.py create-pr --branch doc-update
```
The tool will:
1. Create a new branch named `doc-update`.
2. Commit any documentation changes.
3. Push the branch and open a pull request on GitHub.
